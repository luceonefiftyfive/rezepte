# Frontend Navigation

## Header Navigation and Recipe Actions

The app navigation uses a hamburger menu in the header to switch between Recipes, System, and Admin (Admin only with permission).

Recipe actions are also placed in the header:

- The search filters recipes and is active only in the Recipes view.
- The create button (+) is visible only in the Recipes view.
